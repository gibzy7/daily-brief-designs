01 · Editorial

The Ledger — midnight broadsheet

Serif masthead, issue numbering, drop caps, marginalia comments. A newspaper that never existed, for one reader. Fraunces + Source Serif on warm black.

02 · App

Sticky sidebar with live scrollspy, reading progress bar, collapsible cards, score pills, comment threads. A modern RSS reader, but curated. Inter.

03 · Terminal

Transmission — the machine speaks

Monospace boot log, ASCII frames, $ prompts, green-on-black CRT with scanlines. The brief as a system message from the Pi itself. IBM Plex Mono.

Right rail contents, oversized outlined numerals, Playfair headlines, bylines, an actual "meme page". Coffee-table energy, dark edition.
